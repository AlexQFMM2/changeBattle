# Change Battle CLI

纯文本摸鱼版对战工厂。

这个目录放命令行入口和文本交互层，目标是用最轻的方式把“租赁宝可梦、连续挑战、胜后交换”的核心循环先玩起来。

## Direction

- 命令行即可启动。
- 文本展示队伍、招式、道具、属性和战斗信息。
- 调用 `../core` 完成数据读取、随机生成、战斗结算和交换逻辑。
- CLI 自己不重复实现核心规则，只负责展示、输入和流程推进。

## First Prototype

第一版可以先非常粗糙：

- 随机给玩家一组租赁宝可梦。
- 随机生成对手队伍。
- 用简化规则进行战斗。
- 胜利后允许从对手队伍中换一只。
- 记录当前连胜数。
- 支持随机种子，方便复现一局有趣的流程。

它的价值不是画面，而是快速验证这个玩法循环到底好不好玩。

## Run

当前已经可以启动一个最小 3v3 原型：

```bash
python3 changeBattle-cli/play.py
```

带固定随机种子：

```bash
python3 changeBattle-cli/play.py --seed 123
```

输入方式：

- `1`、`2`、`3`、`4`：使用对应技能。
- `s2`、`s3`：切换到对应宝可梦。
- `team`：查看队伍。
- `q`：退出。

当前 CLI 只用于验证基础闭环：随机双方 3 只宝可梦、合法攻击招、速度线、换人、伤害、濒死和胜负。命中、会心、特性、道具、天气等会按 `plan.md` 后续阶段加入。
