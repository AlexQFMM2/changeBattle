# Formal Training Ground Plan

## Summary

正式休整商店第一版已经收口。下一阶段正式设施转向「训练场」。训练场不是固定菜单，而是偏随机的“今日课程”设施：进入休整页或点击上课后，教室会随机出现一位老师或自习课，玩家确认付费后再指定一只宝可梦参与学习。

- 老奶奶上课：学习 tutor / 传授来源技能。
- 老爷爷上课：学习 egg / 蛋技能。
- 年轻小姐上课：学习 levelup / 自学来源技能。
- 自习课：自主训练，随机影响个体值、努力值和等级。

本计划只记录训练场设施第一版，不处理商店、交换、抽奖、奖励扩展或战斗结算。

## Scope

### 1. 随机课程入口

- [x] 新增训练场入口。
- [x] 进入休整页或点击「上课」后，根据 `run.seed + nodeId + lessonRoll` 稳定抽取当前课程。
- [x] 当前课程在同一 `lessonRoll` 内保持稳定，避免玩家反复进出刷同一堂课结果。
- [x] 课程确认前只展示老师、课程文案、费用和确认按钮。
- [x] 玩家确认并付费后，再进入选择宝可梦/学习流程。
- [x] 余额不足失败且不改 run。

### 2. 老奶奶上课：传授技能

- 文案：
  - 「一位年迈慈祥的奶奶正在教学，是否让宝可梦进入学习？旁听费 100 金币。」
  - 完成：「教授课程结束了。」
- [x] 费用：100 金币。
- [x] 指定一只宝可梦学习 tutor / 传授来源技能。
- [x] 从 API 使用现有 `getPokemonTutorSkills(speciesId)` 获取可传授技能。
- [x] 已学会的技能不重复展示，或显示为已学会不可选。
- [x] 学习技能沿用现有 TM 替换技能交互：选择要替换的技能后写回队伍草稿。

### 3. 老爷爷上课：蛋技能

- 文案：
  - 「一位沉稳严厉的爷爷正在教学，是否让宝可梦进入学习？旁听费 100 金币。」
  - 完成：「遗传课程结束了。」
- [x] 费用：100 金币。
- [x] 指定一只宝可梦学习 egg / 蛋技能。
- [x] 从 API 使用现有 `getPokemonEggSkills(speciesId)` 获取遗传来源技能。
- [x] 学习流程复用传授技能的替换技能交互。

### 4. 年轻小姐上课：自学技能

- 文案：
  - 「一位漂亮美丽的姐姐正在教学，是否让宝可梦进入学习？旁听费 200 金币。」
  - 完成：「自学课程结束了。」
- [x] 费用：200 金币。
- [x] 指定一只宝可梦学习 levelup / 自学来源技能。
- [x] 从 API 使用现有 `getPokemonSelfLearnSkills(speciesId)` 获取自学技能。
- [x] 学习流程复用传授技能的替换技能交互。

### 5. 自习课：自主学习

- 文案：
  - 「教室里现在没有老师，大家都在埋头自习，是否让宝可梦自主学习？座位费 200 金币。」
  - 完成文案根据随机事件展示，例如认真学习、普通自习、贪玩。
- [x] 费用：200 金币。
- [x] 指定一只宝可梦自主学习。
- [x] 自主学习可能影响：
  - 数值等级：`powerProfile` 最多提升到 `champion`。
  - 个体值/努力值上限：按新阶段 roll cap，且不低于旧 cap。
  - 个体值/努力值：只追加到实例 cap 内，已满项不再提升。
  - 等级：按事件结果变化。
- [x] 自主学习根据宝可梦性格权重和随机事件决定结果；后续星图偏移也叠加到同一权重入口。
- [x] 第一版事件结果：
  - 贪玩：基础概率 30%，不升 `powerProfile`，在当前 cap 内增长，等级 +1。
  - 普通自习：基础概率 60%，`powerProfile +1`，追加到新 cap，等级 +2。
  - 认真学习：基础概率 10%，`powerProfile +2`，追加到新 cap，等级 +4。
- [x] 属性提升必须保持合法上限，等级不高于 100。
- [x] 结果确认前展示预览，确认后扣金币并写回队伍草稿。

### 6. 课后流程与转场

- [x] 每堂课完成后弹出提示：
  - 「当前课程已结束，是否等待下一堂课开始？」
- [x] 点击确认：
  - `lessonRoll + 1`，进入下一堂随机课程。
  - 下一堂课重新抽取老师/自习课。
  - 留在训练场内，不返回休整中心。
- [x] 点击取消：
  - 直接返回休整中心。
- [x] 进入训练场使用向左移动转场，表现为休整中心向左切到训练场。
- [x] 退出训练场使用向右移动转场，表现为训练场向右回到休整中心。
- [x] 课后等待下一堂课不播放完整退场，只在训练场内切换课程内容。

## Data And Runtime Rules

- 训练场只更新正式 `FormalGameRunV4` 的运行中休整快照，不改 profile 长期数据。
- 所有扣费通过金币流水记录，方便结算页统计。
- 技能合法性只依赖 dex/source API，不手写物种学习表。
- 课程类型必须由 `run.seed + nodeId + lessonRoll` 派生，同一 `lessonRoll` 稳定。
- 等待下一堂课只递增 `lessonRoll`，不需要新建休整节点。
- 自习课随机结果必须由 `run.seed + nodeId + pokemonId + lessonId` 派生，避免同一次确认前反复跳动。
- 自习课性格权重只影响事件概率，不保证必定正收益。
- 队伍详情页移除免费随机技能；技能获取只保留训练场课程和商店技能机器。
- 训练场入口和 UI 状态留在 Web；扣费、合法性和 run patch 规则留在 API。
- 如果后续训练场配置需要静态 catalog，再放入 `@changebattle-v2/core`。

## Non-Goals

- 不实现商店逻辑，商店已经收口。
- 不实现交换、抽奖、奖励来源或星图扩展。
- 不实现完整育成模拟器，例如指定性格、指定全部 EV/IV、遗传链推导。
- 不改变正式战斗结算、存档结构或 Battle V4 runtime。

## Test Plan

- API:
  - 余额不足时任意课程失败且不改 run。
  - 同一 `lessonRoll` 课程稳定，不因反复打开训练场变化。
  - 等待下一堂课后 `lessonRoll` 增加，并能抽到下一堂课程。
  - 成功时金币减少、coinLog 追加、队伍技能或数值正确变化。
  - 非法技能、重复技能、缺少宝可梦、缺少替换槽位时失败且不改 run。
  - 自习课属性和等级变化保持合法上下限。
- Web:
  - 训练场入口展示随机课程文案、费用和确认。
  - 技能列表、替换技能、确认扣费、失败提示正常。
  - 自习课能预览改动，确认后更新队伍显示。
  - 课程结束后弹窗询问是否等待下一堂课；确认留在训练场，取消回休整中心。
  - 进入训练场向左移动，退出训练场向右移动。
- Static:
  - `pnpm --dir changeBattleV2 --filter @changebattle-v2/api typecheck`
  - `pnpm --dir changeBattleV2 --filter @changebattle-v2/web typecheck`
  - `pnpm --dir changeBattleV2 typecheck`
  - `git -C changeBattleV2 diff --check`
