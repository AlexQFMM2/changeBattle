# Plan Archive

这里存放已经收口、明显落后或只适合作为历史背景的计划。归档文件不再代表当前待办；需要继续开发时应在对应功能目录重新开小计划。

## 分组

- `formal-game/`：正式游戏早期总计划/清单，以及正式商店、训练场、中转页迁移、对局偏好、core 数据迁移等已收口计划。
- `battle-v4/ai/`：Battle V4 AI 决策器主体架构和 checklist，当前主体已落地，后续调参按新问题单独开计划。
- `battle-v4/animation/`：Showdown 动画 adapter 第一阶段设计和 checklist，当前动画工作以 `../battle-v4/animation/` 的 deep sync 计划为准。
- `items-and-bag/`：系统战斗道具、统一背包、休整页道具和 Battle V4 道具第一版收口记录。
- `dex-resources/`：V1 道具资源迁移和 QuickDex 道具扩展历史记录。
- `desktop/`：旧版 desktop 文件级增量更新计划，当前发布规范以 `release/README.md` 为准。
