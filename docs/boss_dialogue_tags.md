# Boss 台词标签表

用途：先整理每个 boss 的身份、职业、人设、失败反应和台词素材方向。后续生成 `data/boss_dialogues.json` 时，应优先参考这里的标签，而不是只按属性主题套模板。

原则：
- 不服输型失败后不要大方认输，要嘴硬、找补、迁怒、要求主角别输给别人。
- 职业型优先使用职业话术，例如军人、服务员、博物馆馆长、摇滚歌手、模特、厨师、老师、主播、上班族。
- 强者型可以认可玩家，但要符合姿态：冠军更像总结旅途，四天王更像审核资格，馆主更像地方考验。
- 赤红只允许 `。。。`、`。。。？`、`。。。！` 这类沉默台词。
- 小茂 / 青绿可以少量联动赤红，但不要每句都提。

## 生成优先级

1. 专属人设台词：强性格、强职业、原作辨识度高的 boss 优先手写多组，例如小茜、小椿、马志士、霍米加、聂梓、莱姆、奇树、青木、丹帝。
2. 职业标签台词：教师、馆长、厨师、模特/演员、科学家/工程师等，优先使用职业语汇。
3. 属性/地区主题台词：没有强职业或强性格时，再使用属性主题、地区身份和馆主/四天王/冠军姿态。
4. 战绩变体：首次见面、玩家上次赢、玩家上次输、多次再战要有不同语气。嘴硬型即使输了也不能突然大方祝贺。
