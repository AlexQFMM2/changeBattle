# 随机规则

## 当前状态

以当前代码为准；文中未标 `[x]`、写明“后续/预留”或只描述方向的内容，均视为设计草案。

## 目前的随机规则

生成一只宝可梦时会先决定它的数值分级，也就是 `generation_profile` / `stage_tier`；部分场景还会单独指定物种分级 `species_tier`。最终强度大概是：

```text
最终强度 = 数值分级强度 × 物种分级强度 × Showdown randomSet 招式/特性/道具质量
```

开局候选按当前连续通关数分配数值分级：

```text
0 连胜:
  tier1, tier1, tier1, tier2, tier2, tier2

1 连胜:
  tier1, tier1, tier1, tier2, tier2, tier3

2+ 连胜:
  tier1, tier2, tier2, tier3, tier3, tier3
```

开局候选的物种分级和数值分级分开指定，避免高周目仍大量抽到低档物种：

```text
0 连胜:
  species tier3, tier4, tier4, tier4, tier5, tier5

1 连胜:
  species tier4, tier4, tier5, tier5, tier5, tier6

2+ 连胜:
  species tier4, tier5, tier5, tier6, tier6, tier6
```

普通敌人按下一场 Boss 阶段分配数值分级：

```text
普通早期:
  tier1, tier1, tier2

普通 before_tier2:
  tier2, tier2, tier3

普通 before_tier3:
  tier3, tier3, tier4
```

普通敌人的物种分级单独指定，不再只靠数值 profile 的权重随机，避免普通敌人大量抽到 `species tier1/2` 的弱小未进化物种：

```text
普通早期:
  species tier3, tier4, tier4/tier5

普通 before_tier2:
  species tier3, tier4, tier5/tier6

普通 before_tier3:
  species tier4/tier3, tier5, tier6
```

Boss 按路线分配数值分级。馆主、四天王、冠军这类 Boss 角色的物种来自预处理好的固定队伍池，不现场按物种分级抽奖；这里的分级只用于决定这些固定物种生成出来时的数值强度。

```text
道馆 tier1:
  tier1, tier2, tier2

道馆 tier2:
  tier2, tier3, tier3

高阶道馆 / 四天王:
  tier3, tier4, tier4

冠军:
  champion, champion, champion
```

Boss 固定队伍池会同时记录物种档位目标，数值强度和物种强度分开：

```text
道馆 tier1:
  species tier4, tier4, tier5

道馆 tier2:
  species tier4, tier5, tier5

高阶道馆 / 四天王:
  species tier5, tier5, tier6

冠军:
  species tier5, tier6, tier6
```

`data/boss_team_pools.csv` 现在按 `battle_rule_preset` 生成四套固定池：

```text
none:
  允许 Gen1-9，用作默认池和图鉴预览池

gen7:
  只允许 Gen1-7，并尽量保证每组至少 1 只可 Mega 的物种

gen8:
  只允许 Gen1-8，并尽量保证每组至少 1 只可超极巨化的物种

gen9:
  允许 Gen1-9，太晶属性由开战生成逻辑写入
```

Boss 固定物种不受地区专爱过滤，但受 `battle_rule_preset` 的世代兼容池约束。运行时会先选当前 run 快照对应的 preset 池，如果该 preset 缺失才回退到 `none` 池；小道消息和真实开战都读取同一份预生成队伍。

普通敌人在没有指定固定物种、也没有显式指定物种分级时，数值分级不一定只抽同档物种。当前 profile 到物种分级的抽取权重是：

```text
profile tier1:
  10% 抽 species tier1
  20% 抽 species tier2
  30% 抽 species tier3，偏好非 NFE
  40% 抽 species tier4，偏好非 NFE

profile tier2:
  30% 抽 species tier2
  40% 抽 species tier3，偏好非 NFE
  20% 抽 species tier4，偏好非 NFE
  10% 抽 species tier5，偏好非 NFE

profile tier3:
  20% 抽 species tier3，偏好非 NFE
  50% 抽 species tier4，偏好非 NFE
  30% 抽 species tier5，偏好非 NFE

profile tier4:
  20% 抽 species tier4，偏好非 NFE
  40% 抽 species tier5，偏好非 NFE
  30% 抽 species tier6，偏好非 NFE
  10% 抽 species tier10，神战关闭时回退到普通池
```

这套抽取权重只用于随机物种。抽物种时会避开同一队里已经出现过的物种，并尽量让不同世代分布更均衡。

当前设计倾向是把开局和高档对战主体铺在 `species tier4` 到 `species tier6`，`species tier3` 只作为 0 连胜开局的一只低档波动，`species tier1/2` 主要保留给数据、低档随机权重和弱小未进化，`species tier10` 专门承接神兽/幻兽/特殊神兽多形态。百变怪、图图犬、脱壳忍者、果然翁等低 BST 高战术价值物种会获得 `tactical+` 评分补偿。

神战开关直接控制 `species tier10`：

```text
神战关闭:
  普通随机池排除 species tier10
  Boss 固定队伍不受影响

神战开启:
  species tier10 可以进入普通随机池
  legendary / mythical 仍维持每队最多 1 只
```

## 当前的数值分级规则

数值分级决定等级、道具、个体值总量、努力值总量、性格等养成强度。数值分级仍保留 4 档加 champion，不随物种六档和神兽档同步扩展。

```text
tier1:
  Lv 45-50
  不携带道具
  IV 总量 0-90
  EV 总量 0-200
  性格固定 Serious

tier2:
  Lv 45-50
  携带道具
  IV 总量 60-120
  EV 总量 180-300
  随机性格

tier3:
  Lv 50-54
  携带道具
  IV 总量 90-150
  EV 总量 270-450
  使用 Showdown set 性格或随机性格

tier4:
  Lv 55
  携带道具
  全 31 IV
  EV 总量 510
  使用 Showdown set 性格或随机性格

champion:
  Lv 58-60
  携带道具
  全 31 IV
  EV 总量 510
  使用 Showdown set 性格或随机性格
```

## 当前的物种分级规则

物种分级来自 `data/pokemon_tiers.csv`，生成脚本是 `tools/build_team_generation_data.js`。它决定“抽哪个物种池”，比如弱小未进化、普通最终形、强力最终形、神兽/高种族值形态。

当前评分公式：

```text
score = BST
      + nfePenalty
      + legendaryBonus
      + randomLevelScore
      + evioliteBulkBonus
      + randomSetEvioliteBonus
      + tacticalBonus
```

具体规则：

```text
BST:
  六项种族值总和

nfePenalty:
  NFE / 未最终进化: -45
  非 NFE: +45

legendaryBonus:
  legendary 或 mythical: +90
  其他: +0
  注：legendary / mythical 最终直接进入 species tier10，不参与普通六档切分；熊徒弟 / 武道熊师 / 武道熊师（连击流）按非神兽覆盖进入 species tier6

randomLevelScore:
  如果有 Showdown gen7 randbat level:
    max(0, 100 - random_battle_level) * 3
  否则 +0

bulkScore:
  hp + def + spd

evioliteBulkBonus:
  仅 NFE 生效
  round(clamp((bulkScore - 220) / 2, 0, 80))

randomSetEvioliteBonus:
  如果 Showdown gen7 randomSet 给的道具是 Eviolite: +40
  否则 +0

tacticalBonus:
  百变怪、图图犬、脱壳忍者、果然翁等低 BST 高战术价值物种获得额外补偿
```

普通物种按 `score` 从低到高排序，然后六等分成 `species tier1` 到 `species tier6`。legendary / mythical 单独进入 `species tier10`，但熊徒弟 / 武道熊师 / 武道熊师（连击流）按非神兽覆盖进入 `species tier6`。边界分数有可能重叠，因为普通六档按排序序号切，不按固定分数阈值切。
