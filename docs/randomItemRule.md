# 道具随机规则

## 当前状态

以当前代码为准；文中未标 `[x]`、写明“后续/预留”或只描述方向的内容，均视为设计草案。

## 目前的随机规则

道具随机分成两套池：

```text
开局道具:
  数据来自 data/starter_item_pool.csv
  在新游戏进入选队前生成
  按“战斗道具 / 恢复道具 / 树果 / 技能机器”4 类分别抽
  候选免费，玩家每类默认最多带走 1 个

休整商店:
  数据来自 data/shop_pool.csv
  在每场战斗后的休整页抽奖
  按“治疗 / PP / 树果 / 技能机器 / 携带道具”桶先抽类别，再抽具体道具
  玩家花金币购买抽出来的商品
```

开局道具的“数量”和“质量”由局外“开局筹备”强化决定：

```text
新存档默认:
  战斗道具数量 Lv2，质量 Lv1
  恢复道具数量 Lv2，质量 Lv1
  树果数量 Lv2，质量 Lv1
  技能机器数量 Lv2，质量 Lv1

数量 LvN:
  该类别生成 N 个候选

质量 LvQ:
  该类别只会从 tier <= Q 的开局道具池里抽
```

开局道具每个类别内部独立抽取，不会在同一类别里重复抽到同一个道具。抽取权重会根据当前质量等级偏向接近上限的道具：

```text
道具 tier == 当前质量 Lv:
  基础权重 x3

道具 tier == 当前质量 Lv - 1:
  基础权重 x2

其他可抽道具:
  基础权重 x1
```

因此默认质量 Lv1 时，只会抽各类 `tier1` 道具；把质量升高后，低 tier 仍然可能出现，但更接近当前质量上限的道具权重更高。树果和战斗道具现在每个质量档都有可用池，升级质量会直接扩大候选范围。

休整商店每次抽奖默认给 3 格商品；拥有“顺手牵羊”后给 4 格。每一格先抽类别桶，再从该桶内洗出候选池并按道具权重抽具体商品。

```text
商店类别桶权重:
  治疗: 65
  PP: 15
  树果: 10
  技能机器: 5
  携带道具: 5

默认候选池大小:
  每格从对应类别洗出 4 个候选，再按道具权重抽 1 个

拥有“顺手牵羊”:
  每格从对应类别洗出 8 个候选，再按道具权重抽 1 个
```

拥有“神机妙算”后，商店抽奖前可以额外花费 `100` 金币指定方向：

```text
指定治疗:
  只抽治疗桶

指定 PP:
  只抽 PP 桶

指定树果:
  只抽树果桶

指定战斗道具:
  只抽携带道具桶

指定技能机器:
  只抽技能机器桶
```

商店每次抽完会检查结果里是否有恢复保底道具。如果没有，会把第 1 格替换成一个随机恢复保底道具。

```text
恢复保底池:
  回复药，好伤药，绝好伤药，全满药，全复药，活力碎片，活力块，复活草，万灵药，万能粉，解毒药，灼伤药，解冻药，解眠药，解麻药
```

技能机器不是固定道具名单，而是动态池：

```text
开局技能机器:
  先生成一组开局候选宝可梦
  收集这些宝可梦当前招式中的可用招式
  洗牌后取最多 24 个，作为开局技能机器候选池

商店技能机器:
  收集当前队伍可学习的招式
  洗牌后取最多 24 个，作为商店技能机器候选池
```

Boss 胜利奖励不走商店随机池：

```text
普通战胜利:
  固定给 2 个万灵药或苹野果
  固定给 1 个活力碎片或绝好伤药
  固定给 1 个全复药

Boss 战胜利:
  固定给 2 个全复药
  固定给 2 个 PP 多项全补剂
  下一次休整额外 1 次免费商店抽奖，并给商店格子折扣
```

## 当前的开局道具分级规则

开局道具分级来自 `data/starter_item_pool.csv`。字段含义是：

```text
starter_group:
  recovery = 恢复道具
  berry = 树果
  battle = 战斗道具
  tm = 技能机器

tier:
  受“道具质量”等级限制

weight:
  基础抽取权重

discountable:
  当前开局候选免费带走；该字段保留给后续折扣/价格逻辑
```

```text
kind:
  item = 固定道具

category:
  consumable = 消耗品
  held = 携带道具

  商店购买价格，单位是金币

weight:
  在所属类别桶内的基础抽取权重
```
