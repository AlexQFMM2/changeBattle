# 道具随机规则

## 当前状态

以当前代码为准；文中未标 `[x]`、写明“后续/预留”或只描述方向的内容，均视为设计草案。

## 多商店与熔炉 v1

休整页商店已从单一混合抽奖拆成多个功能区：

```text
回复商店:
  抽奖费用 50 金币
  主色绿色
  从恢复药、树果、PP 补剂三类中随机

道具商店:
  抽奖费用 75 金币
  主色蓝色
  只抽普通战斗携带道具
  不包含 Mega 石、Z 纯晶、太晶珠

技能商店:
  抽奖费用 75 金币
  每次固定 3 张技能机器
  其中 2 张当前队伍至少 1 只宝可梦能学
  其中 1 张当前队伍都不能学，但未来换队后可能有用
```

原“神机妙算”的指定方向被多商店天然选择替代；免费商店抽奖优先抵扣当前选择的商店。

熔炉规则：

```text
普通熔炉:
  投入 3 个背包道具
  不额外收费
  3 个材料类型一致时产出 2 个不同重铸物
  类型不一致时产出 1 个重铸物
  普通携带道具重铸池不包含 Mega 石、Z 纯晶、太晶珠

特殊熔炉:
  投入 1 个 Mega 石或 Z 纯晶
  花费 50 金币
  随机获得同系统的另一个不同特殊道具

太晶珠重铸:
  太晶珠仍是本局状态，不进背包
  花费 50 金币
  将本局太晶珠随机变成另一个不同属性
```

技能来源规则：

```text
技能机器商店:
  只使用 Showdown learnset 中的 M 来源

金币抽技能:
  只抽自学 L 与遗传 E 来源
  不包含技能机器 M、教授 T、事件 S、转移 V/D 等来源
```

## 目前的随机规则

道具随机分成开局道具和休整功能区两套入口：

```text
开局道具:
  数据来自 data/starter_item_pool.csv
  在新游戏进入选队前生成
  按“战斗道具 / 恢复道具 / 树果 / 技能机器”4 类分别抽
  候选免费，玩家每类默认最多带走 1 个

休整功能区:
  数据来自 data/shop_pool.csv
  在每场战斗后的休整页使用
  回复商店、道具商店、技能商店分别抽奖
  熔炉消耗背包材料重铸
```

开局道具的“数量”和“质量”由局外“开局筹备”强化决定：

```text
新存档默认:
  战斗道具数量 Lv2，质量 Lv1
  恢复道具数量 Lv2，质量 Lv1
  树果数量 Lv2，质量 Lv1
  技能机器数量 Lv2，质量 Lv1

数量 LvN:
  该类别生成 N 个候选

质量 LvQ:
  该类别只会从 tier <= Q 的开局道具池里抽
```

开局道具每个类别内部独立抽取，不会在同一类别里重复抽到同一个道具。抽取权重会根据当前质量等级偏向接近上限的道具：

```text
道具 tier == 当前质量 Lv:
  基础权重 x3

道具 tier == 当前质量 Lv - 1:
  基础权重 x2

其他可抽道具:
  基础权重 x1
```

因此默认质量 Lv1 时，只会抽各类 `tier1` 道具；把质量升高后，低 tier 仍然可能出现，但更接近当前质量上限的道具权重更高。树果和战斗道具现在每个质量档都有可用池，升级质量会直接扩大候选范围。

休整页多商店规则：

```text
回复商店:
  抽奖费用 50 金币
  每次默认 3 格，顺手牵羊后 4 格
  从治疗 / PP / 树果桶中抽取
  若没有恢复保底道具，会把第 1 格替换为恢复保底

道具商店:
  抽奖费用 75 金币
  每次默认 3 格，顺手牵羊后 4 格
  只抽普通携带道具
  排除 Mega 石、Z 纯晶和太晶珠

技能商店:
  抽奖费用 75 金币
  每次固定 3 张技能机器
  2 张当前队伍至少 1 只宝可梦能学
  1 张当前队伍都不能学
```

回复商店恢复保底池：

```text
回复药，好伤药，绝好伤药，全满药，全复药，活力碎片，活力块，复活草，万灵药，万能粉，解毒药，灼伤药，解冻药，解眠药，解麻药
```

技能机器不是固定道具名单，而是动态池：

```text
开局技能机器:
  先生成一组开局候选宝可梦
  收集这些宝可梦当前招式中的可用招式
  洗牌后取最多 24 个，作为开局技能机器候选池

商店技能机器:
  收集当前队伍可通过 machine 来源学习的招式
  再从全局 machine 来源招式里补 1 张当前队伍不能学的技能机器
  固定展示 3 张
```

战斗胜利不再自动发放回复/PP/复活道具：

```text
普通战胜利:
  不再固定掉落道具
  只保留金币胜利奖励

Boss 战胜利:
  不再固定掉落道具
  不再固定给下一次商店免费抽奖/商品折扣
  后续续航主要依赖回复商店、背包存量、交换带来的状态变化，以及休整奇遇
  道具回收商由休整奇遇开启，不再战后自动出现
```

```text

  recovery = 恢复道具

  battle = 战斗道具

tier:

  当前开局候选免费带走；该字段保留给后续折扣/价格逻辑
```
