# ChangeBattle 规则草案

## 游戏说明

ChangeBattle 现在不是原版对战工厂的复刻，也不再只是“随机租赁队伍，然后打连续战斗”。它的核心已经变成一个短周期的宝可梦 Boss Rush Roguelite：玩家从一组随机候选中拿到不完美的初始牌组，通过普通战、战后交换、商店、技能调整、数值改造、道具管理和开局筹备，把临时队伍逐步养成能突破馆主、四天王和冠军压力的阵容。

一局挑战以 7 场为一个完整循环。Boss 不再像原版那样隔很长周期才出现，而是在第 3 场和第 7 场固定形成阶段验收；连续通关后，Boss 档位继续提高，最终进入冠军线。因此普通 NPC 不是单纯的杂兵，而是玩家补牌、换牌、赚续航和修正队伍方向的主要窗口；Boss 战也不只是更强的敌人，而是路线节点、压力测试和高价值战利品来源。

玩家每局需要同时处理四件事：

- 用随机发到的宝可梦和道具撑过前期。
- 在普通战后通过交换、商店、技能和数值改造补齐队伍短板。
- 根据即将到来的 Boss 类型和路线压力，决定局内金币要花在当下战力、长期收益、情报、续航还是高风险爆发上。
- 在连续通关中面对越来越密集、越来越强的 Boss Rush，把一支临时队伍滚成有体系的阵容。

因此，ChangeBattle 的核心乐趣不是“随机给什么就只能用什么”，而是“随机发牌之后如何把牌打活”。BP 是局外成长资源，金币是局内运营和改造预算；道具掉落和商店负责续航；交换是队伍成长的主轴之一。当前天赋系统已经按新结构重新启用，天赋不再只是按钮优惠，而是代表不同的局内战略路线。

当前天赋按“路线视图”整理：

- 开局筹备路线：改变初始金币、初始道具容量、开局宝可梦数值模板和上一局回忆候选。
- 交换筑队路线：强化普通战或 Boss 战后的交换价值，并提供战后信赖培养。
- 情报规划路线：提前看到训练师、Boss、阵容或关键威胁，方便针对性筑队。
- 养成改造路线：强化技能、数值、商店选择、首发调整和高风险爆发。
- 经济运营路线：提高金币入账、BP 救急、出售或返还效率，并在结算时转化为更多 BP。

规则设计时不能再完全沿用原版对战工厂的节奏判断。原版偏向长线随机租赁与低频 Boss 验收；ChangeBattle 则是短周期筑队、密集 Boss 压力和局内养成共同驱动的结构。普通战、Boss 奖励、馆主交换、情报天赋、经济天赋和失败保护，都需要按这个新节奏重新评估。

标记说明：`[x]` 表示当前主流程已实现；`[ ]` 表示规则已确定但还没完整落地。若只在某一端完成，会在条目里标注 Desk/CLI。

## 核心目标

- 每一局都有随机候选、随机普通对手、随机商店、临时背包和固定节奏 Boss，形成短周期局内构筑。
- 普通 NPC 负责提供成长窗口，Boss 负责阶段验收和路线压力。
- BP 是局外成长货币，金币是局内运营货币；玩家需要在“现在变强”“长期收益”“信息规划”和“保留容错”之间取舍。
- 宝可梦不再只是固定租赁单位，而是可以通过技能、道具、数值、交换和局外成长系统逐步塑形。
- 天赋系统已重新启用；旧天赋 ID 不做兼容映射，旧存档中不存在于新目录的解锁和装备会被过滤。

## 核心概念

### BP 和金币

BP 是局外长期货币，只负责开局筹备升级、后续天赋等局外成长；金币是单局内的运营货币，负责休整改造、商店、交换、情报和救援等局内操作。两者不再混用。

基础规则：

- [x] 新建存档初始化获得 `50BP`，作为第一批局外成长资金。
- [x] 开局筹备升级和天赋解锁都使用 BP，按整数结算，不允许为负数。
- [x] 每局挑战默认开局金币为 `0`。
- [x] 局内胜利、出售道具、背包返还和通关奖励都进入本局金币池。
- [x] 局内消费只扣金币，不再直接扣 BP。
- [x] 挑战结束时，当前金币按 `1BP = 100金币` 向下取整折算为 BP；不足 100 的金币不结转。
- [x] 取消开局准备只返回主菜单，不标记失败、不中断连胜，也不需要 BP 返还。
- [x] 中断已经开始的挑战会结束本局，并将当前连续通关归零；本局剩余金币仍按规则折算 BP。

### 金币经济基准

当前版本每场胜利固定获得 `500金币`，通关时额外获得连续通关奖励。以 7 场全胜为基准：

- [x] 小场胜利收入：`7 * 500 = 3500金币`。
- [x] 第 1 次通关奖励：`900金币`，来自 `(连续通关次数 * 2 + 7) * 100`。
- [x] 连续通关奖励会随连续通关次数提高：第 2 次为 `1100金币`，第 3 次为 `1300金币`，之后每连续通关 1 次多 `200金币`。
- [x] 因此无加成、无背包返还时，一次完整首通关总金币收入约为 `4400金币`，结算约 `44BP`。
- [x] 普通闪光加成会作用于所有正向金币入账，包括小场胜利、背包返还和通关奖励；`护符金币`、`闪光收藏家` 按新天赋规则生效。

局内常见消费基准：

- [x] 普通休整交换同一轮最多 3 只，费用为 `0 / 100 / 200金币`；馆主/四天王默认只允许交换 1 只，费用 `200金币`；冠军默认不可交换。
- [x] 普通商店每次休整第 1 次抽奖免费，之后每次 `150金币`；抽到商品后购买商品仍需额外付道具价格。
- [x] 随机抽技能每次 `200金币`；技能机器可在休整页一次性使用。
- [x] 随机单项数值每次 `100金币`，随机全部数值每次 `200金币`，精确调整数值每次 `1000金币`。
- [x] 小道消息查看完整单场阵容每次 `300金币`；每场免费揭示 1 只。
- [x] 神机妙算指定商店类型每次额外 `100金币`。
- [x] 旧版二队重打机制已移除，不再作为天赋或常规救援入口。

胜利奖励会补足一部分消耗，但主要是道具而不是现金：

- [x] 普通 NPC 胜利会给 2 个状态/PP 恢复道具、1 个中高档治疗/复活道具、1 个全复药。
- [x] Boss 胜利会给 2 个全复药、2 个 PP 多项全补剂，并让下一次休整获得 1 次免费商店抽奖和商品格折扣。
- [x] 金币是局内“改造预算”，续航主要依赖胜利掉落、背包和商店选择；如果玩家把金币同时用于治疗、商店、技能和数值，500金币/场的现金体感会偏紧。

经济判断：

- [x] 以当前实现看，完整通关的基础金币流是正向的：首通约 +4400金币，后续连续通关更高。
- [x] 如果每次休整都做 1 次交换、1 次随机技能、少量商店抽奖，基础金币还能支撑；如果频繁精确调数值、小道消息详查和多次商店抽奖，现金会很快吃紧。
- [x] 当前明显的正向经济天赋是天使基金、护符金币、座上贵宾、铤而走险、闪光收藏家、贵客专属和有借有换。
- [x] 部分天赋不是现金正向，而是提高队伍质量或降低信息风险，例如伯乐本乐、英才教育、顺手牵羊、上帝之眼、小道消息和临阵换将；这些方向主要通过提高通关率体现价值。

### 战斗背包

战斗背包是局内共享背包，只在当前挑战中使用。

- [x] 道具购买后进入战斗背包。
- [x] 道具可分为恢复类、树果类、战斗道具类、技能机器类。
- [x] Desk 消耗道具允许在战斗中使用，也允许在休整页使用。
- [x] Desk 战斗中主动使用消耗道具会占用当前宝可梦本回合行动，道具效果必定先制，然后对手行动与回合末结算继续由 Showdown 处理。
- [x] Desk 战斗内主动道具只开放 `data/consumable_item_effects.csv` 中的稳定效果；能力提升、清复杂状态、清场地等道具暂不作为主动消耗品开放。
- [ ] CLI 战斗中使用消耗道具。
- [x] Desk 技能机器是一次性消耗道具，使用后从战斗背包中移除。
- [x] Desk 所有道具默认支持半价金币出售。
- [x] Desk 挑战通关或中断时，背包内剩余可返还道具按 25% 金币加入本局结算；携带贵客专属时提高到 50%。
- [x] Desk 战斗失败时，背包内剩余可返还道具只按 10% 金币加入本局结算；携带贵客专属时提高到 20%。

### 天赋

天赋是局外养成系统，当前 Desk 已重新启用。天赋页使用“路线视图”，不再显示旧的交换/赌徒/先知/经营四分类。旧天赋 ID 不做兼容映射，加载存档时会过滤掉不存在于新目录的旧解锁和旧装备。

- [x] Desk 可解锁、装备和卸下新天赋；每局最多携带 `5` 个天赋。
- [x] Desk 天赋路线：开局筹备、交换筑队、情报规划、养成改造、经济运营。
- [x] Desk 旧的二队的怒吼、无损交易、直接选技能、好运连连、贵客专享、奇货可居等旧 ID 已从新目录移除，不再生效。
- [ ] CLI 天赋页后续随新天赋系统一起重做。

开局筹备路线：

- [x] 天使基金（20BP）：开局获得 `1000金币`。
- [x] 伯乐本乐（25BP）：开局选中的每只宝可梦有 `33%` 概率升 1 阶，仅限数值模板，最高 4 阶；不改变物种、技能、特性、道具。
- [x] 扩容背包（20BP）：开局道具每一类最多可以选择 `2` 个。
- [x] 灵魂伴侣（30BP）：开局追加上一局我方队伍和最后敌方队伍形成的回忆候选；最多选 1 只回忆候选，再从本局候选选 2 只；也可以跳过回忆候选直接本局 6 选 3。

交换筑队路线：

- [x] 不负信赖（20BP）：每场结束后可选择队内 1 只宝可梦提升 2 级，最高 55 级；溢出等级按 `1级 = 100金币` 转换。
- [x] 馆主认可（15BP）：馆主和四天王宝可梦不再受默认只能交换 1 只的限制；冠军宝可梦默认不可交换。
- [x] 爱护有加（8BP）：交换获得的宝可梦满 HP、满 PP 加入，并获取目标身上的道具。
- [x] 英才教育（12BP）：交换来的宝可梦品质更高；只改变阶级数值，不改变技能、特性和道具。
- [x] 坚毅不倒（20BP）：每场胜利后，队内存活宝可梦至少恢复到 `1/2` 最大 HP，濒死宝可梦恢复到 `1/4` 最大 HP。
- [x] 工厂自由（40BP）：所有交换免费，但不解除 Boss 交换次数限制。

情报规划路线：

- [x] 小道消息（30BP）：休整时可查看本局训练师顺序，并逐步揭示他们的阵容。
- [x] 上帝之眼（8BP）：对战时显示技能打击效果，允许查看图鉴，并显示个体值和努力值。
- [x] 神机妙算（18BP）：商店抽奖前可额外花费金币指定道具方向。
- [x] 公子驾到（25BP）：休整时可强行更换下一场同等级对手，每局最多 3 次；只能在同位置、同路线、同 Boss 类型池内改道，冠军战不可改道。
- [x] 指名挑战（25BP）：开局前指定本局冠军路线的最终 Boss；只在最终战为冠军时生效，不改变中途路线。

养成改造路线：

- [x] 铤而走险（12BP）：局内金币花费和休整页消耗道具可能出现更好或更坏的结果。
- [x] 顺手牵羊（10BP）：商店老虎机、商店候选池和技能随机候选给出更多选择。
- [x] 时也命也（12BP）：重置数值时可能免费，也可能付出更高代价。
- [x] 座上贵宾（20BP）：每次休整获得额外免费商店抽奖机会，后续付费抽奖变贵。
- [x] 孤注一掷（50BP）：每局限一次，生成 1 只 4 阶宝可梦用于交换；交换后另外两只宝可梦半血并睡眠，且立即结束休整；下一场获胜后当前金币翻倍。
- [x] 临阵换将（8BP）：允许在休整页更换下一场首发宝可梦。

经济运营路线：

- [x] 有借有换（10BP）：休整页可按 `1BP => 50金币` 兑换救急资金。
- [x] 回收票据（15BP）：挑战结束时，根据道具回收商出售流水和背包返还经营额追加 `15%` 金币收益。
- [x] 投资组合（20BP）：通关结算时，按本局金币消费覆盖类型返利；交换、商店、技能、数值、情报每覆盖 1 类返还 `200金币`。
- [x] 护符金币（35BP）：所有正向金币入账获得 `1.35倍` 收益。
- [x] 闪光收藏家（40BP）：交换获得的宝可梦均为闪光，且闪光带来的金币加成提高。
- [x] 讲价高手（20BP）：道具回收商出现时，出售道具获得 `75%` 原价；默认回收价为 `50%` 原价。
- [x] 贵客专属（25BP）：挑战通关或中断时可返还道具的结算效率从 `25%` 提高到 `50%`；战斗失败时从 `10%` 提高到 `20%`。

## 一局挑战流程

### 1. 天赋配置

- [x] Desk 主页保留天赋配置页入口，可解锁、装备和卸下当前新天赋。
- [ ] CLI 天赋配置入口后续随新天赋系统一起重做。

### 2. 开局准备

每次开始游戏先进入开局准备态。开局准备不消耗局外 BP，也不再生成随机开局金币；玩家返回主菜单只会取消本次准备，不会判负、不会中断连续通关，也没有 BP 返还问题。

- [x] Desk 默认开局金币为 `0`。
- [x] Desk 从 `data/starter_item_pool.csv` 按“开局筹备”等级生成开局道具，开局池和普通商店池分离，方便单独控制节奏。
- [x] 开局道具分为战斗道具、恢复道具、树果、技能机器 4 类，每类道具池分为 1-4 级。
- [x] 每类有“数量”和“质量”两条 BP 升级。新存档数量默认 Lv2、最高 Lv4，每升 1 级多 1 个候选；质量默认 Lv1、最高 Lv4，限制该类最高能出几级道具，并让高等级道具权重更高。

### 4.1 敌方 AI 强弱规则

敌方 AI 强弱不只靠数值，也靠“知道多少”和“思考多深”区分。AI 会在每个回合玩家操作开始前异步启动决策，基于当时的战斗快照预先计算敌方选择；玩家点击出招、换人或使用战斗道具时只等待这份预案完成，不在玩家点击后重新读心式计算。

| 敌人类型 | AI 档位 | 情报范围 | 决策能力 | 随机性 |
| -------- | ------- | -------- | -------- | ------ |
| 普通 NPC | `normal` | 知道玩家后排物种，不知道全部招式/道具 | 会根据克制、伤害、击杀机会和换人风险做基础判断 | 较高，保留路人训练家的失误感 |
| 一阶/二阶馆主 | `gym_low` | 知道玩家队伍物种和大致属性 | 小候选搜索往后模拟 1 回合，预测玩家最合理的 1-2 个行动 | 中等 |
| 三阶馆主 | `gym_high` | 知道玩家队伍、招式、道具和速度线 | 小候选搜索往后模拟 2 回合，更重视反杀、换人和残局 | 较低 |
| 四天王 | `elite4` | 知道玩家队伍、招式、道具和速度线 | 小候选搜索往后模拟 2 回合，候选数量和预测权重更高 | 低 |
| 冠军 | `champion` | 近似全知 | 小候选搜索往后模拟 3 回合，近似全知但保留少量随机和后续性格偏好，避免机械读心 | 很低 |

当前第一版 AI 已实现：

- [x] 每回合开始时为敌方启动异步预计算，并缓存本回合敌方选择。
- [x] 玩家出招、换人和使用战斗道具都消费同一份敌方预案，避免点击后重新计算造成读心感。
- [x] 敌方出招从纯随机升级为评分选择：基础威力、属性克制、STAB、命中率、击杀机会、低血量先制和自损风险都会影响评分。
- [x] 敌方会按 AI 档位评估状态招、强化招、场地/天气/撒场类招式。
- [x] 敌方会按 AI 档位考虑主动换人，当前主要参考当前火力、承伤风险、低血量和后排反制压力。
- [x] 馆主、四天王和冠军启用小深度搜索：一阶/二阶馆主往后模拟 1 回合；三阶馆主/四天王往后模拟 2 回合；冠军往后模拟 3 回合。
- [x] 搜索只枚举双方最高评分的少量候选行动，并有每回合预算：普通 NPC 25ms，低阶馆主 120ms，高阶馆主 280ms，四天王 450ms，冠军 900ms。
- [x] 性格偏好只对冠军启用，不扩散到普通 NPC、馆主或四天王。当前支持均衡、进攻、防守、异常消耗、强化、适应六类偏好。
- [x] 冠军性格映射：赤红/阿渡/阿戴克/库库伊/丹帝/妮莫偏进攻；大吾/也慈偏防守；米可利偏异常消耗；艾莉丝/卡露妮偏强化；青绿/竹兰偏适应；未匹配冠军偏均衡。

## 宝可梦生成规则

随机生成的宝可梦需要按当前路线阶段逐步变强，而不是所有场次都使用同一强度。

- [x] 新增 `data/pokemon_tiers.csv`，覆盖当前 Gen7/USUM 可用且有图资源的宝可梦；第一版按 Showdown 随机对战强度、种族值、进化阶段、传说/幻兽等自动评分分为 4 阶，并保留 `override_tier` 供后续手工微调。
- [x] CLI 和 Desk 的开局候选、普通 NPC、Boss 均走四阶段生成接口。
- [x] 生成时优先使用 Showdown Gen7 random set 作为专业技能、特性、道具基础；若 Showdown 无法生成，则回退到合法技能池和随机特性/道具。
- [x] 所有阶段默认保留 1/30 闪光概率，并在 display/save 中记录 `shiny`。
- [x] 休整页“重置数值”无视阶段规则，继续按现有合法随机重置。
- [x] 结算获取金币时，队伍中每有 1 只闪光宝可梦，场次结束金币乘以 1.1；拥有闪光收藏家时，每只闪光的金币加成变为 1.3 倍。
- [x] 开局候选不默认保底闪光；闪光收藏家只影响交换获得的宝可梦，不影响开局候选。

阶段现在拆成两层：

- `stage_tier` / `generation_profile`：强度模板，决定等级、个体值、努力值、道具、性格。
- `species_tier`：物种来源档位，决定从 `data/pokemon_tiers.csv` 的哪一档物种池抽。
- 二者可以不同，例如一只 `species_tier=3` 的宝可梦可以套 `generation_profile=tier1`，表现为“普通形态/高档物种，但一阶数值”。
- 指定物种的场景不走混合物种池，例如 Boss 代表队伍、交换升阶时保留原物种；这些场景只套对应强度模板，并记录该物种原本的 `species_tier`。

物种来源混合策略：

| 强度模板 | 物种来源规则 | 说明 |
| -------- | ------------ | ---- |
| 一阶     | `20% 一阶物种 + 60% 二阶物种 + 20% 三阶物种` | 一阶强度不再只从一阶物种池抽，避免开局过多宝宝/未进化宝可梦；其中一半二阶抽取和全部三阶抽取优先避开 `notes=nfe` |
| 二阶     | `30% 二阶物种 + 70% 三阶物种` | 降低未进化密度，让中前期对手和候选更像正常宝可梦 |
| 三阶     | `100% 三阶物种` | 保持原阶段来源，并优先避开 `notes=nfe` |
| 四阶     | `100% 四阶物种` | 保持原阶段来源 |
| 冠军专属 | `100% 四阶物种` | 使用四阶物种池，但套冠军等级和满训练模板 |

四阶段数值规则：

| 阶段     | 等级  | 个体值总和   | 努力值总和 | 道具         | 性格/配置                                   |
| -------- | ----- | ------------ | ---------- | ------------ | ------------------------------------------- |
| 一阶     | 45-50 | 0-90         | 0-200      | 无道具       | 性格固定认真，技能/特性偏随机               |
| 二阶     | 45-50 | 60-120       | 180-300    | 随机战斗道具 | 随机性格                                    |
| 三阶     | 50-54 | 90-150       | 270-450    | 带道具       | 优先 Showdown 专业配置和适配性格            |
| 四阶     | 55    | 186（全 31） | 510        | 带道具       | 优先 Showdown 专业配置和适配性格            |
| 冠军专属 | 58-60 | 186（全 31） | 510        | 带道具       | 冠军是唯一能突破普通阶段等级限制的关底 Boss |

路线难度分布：

- [x] 开局 6 选 3 按历史连续通关数生成：连胜 0 为 `3 个一阶 + 3 个二阶`；连胜 1 为 `3 个一阶 + 2 个二阶 + 1 个三阶`；连胜 >=2 为 `1 个一阶 + 2 个二阶 + 3 个三阶`。
