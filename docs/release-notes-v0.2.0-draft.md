# ChangeBattle V2 v0.2.0 候选更新通知

> 状态：草稿。本文档用于 0.2.0 系统性测试前的更新说明整理；正式 0.2.0 release notes 以测试完成后的版本为准。

## Summary

v0.2.0 是在 v0.1.0 Windows Desktop portable release 之后的一次阶段性收口。这个版本不再继续追加新功能，重点是把过去几轮 beta/debug 中完成的架构拆分、正式流程、灵魂伴侣、长期仓库、增量更新、域名发布和 EXE 启动体验整理成一个可系统测试的候选版本。

## 面向玩家的主要变化

### 灵魂伴侣系统

- 灵魂伴侣从“领取蛋”开始：正式赛最终胜利后，如果点亮了星图节点“灵魂伴侣”，工厂会允许你从本局并肩作战过的己方宝可梦里选择一只，点击“就决定是你了”进入蛋孵化流程。
- 蛋会当场孵化并送入箱子：孵化演出结束后，会生成所选宝可梦进化链的最小形态，等级固定为 50，并提示“已送入玩家的宝可梦箱子”。它会成为新的长期宝可梦养成起点。
- 围绕灵魂伴侣新增了一整条星图分支：
  - `灵魂伴侣`：最终胜利后开启宝可梦蛋选择和孵化入口。
  - `欧洲父母`：提高灵魂伴侣蛋的闪光概率。
  - `一眼万年`：提高孵化后灵魂伴侣的初始亲密度。
  - `进口奶粉`：待结算休整页购买的养成物资可以带出工厂，进入长期道具仓库。
  - `育儿基金`：待结算休整页第一次购买养成物资时，额外获得一笔金币补贴。
- 仓库里的灵魂伴侣可以长期养成：孵化出的宝可梦会进入训练家仓库，可以使用训练道具、进化道具、携带道具等局外养成内容。
- 灵魂伴侣可以通过亲密度进化：亲密度达到要求后，可以配合进化道具继续成长，不再停留在孵化初始形态。
- 灵魂伴侣可以重新陪你进工厂：点亮 `同行许可 I / II` 后，正式模式开局可以追加仓库宝可梦候选；点亮 `爱不释手` 后，通过同行许可带入的宝可梦可以保留携带道具一起进入战斗。
- 灵魂伴侣可以在战斗中成长：正式局单场胜利后，同行的灵魂伴侣会获得亲密度；亲密度达到条件后，可以在战斗流程中触发进化，并播放专门的进化表现。
- 战斗内进化表现补齐：进化时会出现白光演出，战斗面板、名字、图标、立绘和 HP 展示会同步切换到新形态，不再只是后台数据变化。
- 新增灵魂伴侣羁绊旁白：高状态、低血量、进化等场景下，会出现更有陪伴感的战斗旁白，例如鼓劲、撑住、期待你指挥之类的表现。
- 勋章机制加入长期养成：灵魂伴侣可以获得地区制霸等荣誉勋章，仓库页会展示这些长期荣誉，让一只宝可梦的冒险经历更有纪念感。

### 仓库与养成

- 全局仓库重做：长期宝可梦和长期道具进入统一仓库。你可以整理宝可梦、查看详情、管理携带物、使用养成道具、执行进化、放生，以及保存自己的长期资产。
- 仓库养成更完整：训练类道具、进化道具、携带道具等长期养成内容进入仓库体系。局外培养和正式局内战斗的边界更清楚。
- 正式局内道具体系调整：正式模式中，局内养成主要改为使用特效药等局内资源；长期仓库里的训练药、进化材料等不会随便被局内流程消耗，避免长期资产被误用。

### 体验优化

- 训练家星图更顺手：点亮和升级星图节点时，页面会先在本地记录修改，返回时统一保存，操作不再频繁卡顿。清空星图会返还已花费 BP，方便重新规划路线。
- 页面保存体验统一：仓库、星图等长期资产页面开始采用“先编辑、返回时保存”的思路，减少每点一次就保存造成的等待感。
- 正式模式流程继续打磨：开局、赛程、休整、战斗、战后结算和最终结算的闭环更完整，正式局结束后会把该回写的长期收益同步回仓库。
- Desktop 启动体验升级：Windows 包新增 `ChangeBattle V2.exe`，默认双击 EXE 启动，不再要求玩家优先运行 `.cmd`；`.cmd` 仍保留为 fallback/debug 入口。

## 工程与发布变化

- 源码结构继续拆分：核心规则沉到 `packages/changebattle-v2-core`，API/Web/Desktop 负责各自编排与展示，减少规则散落在前端页面或 desktop 侧的情况。
- 灵魂伴侣生命周期边界修正：core 只保留纯规则计算；正式 run、localTeam、仓库亲密度和携带道具写入收回 API 层，避免 core 直接改仓库。
- Desktop 增量更新接入：release 会生成 file manifest，支持按 managed files 比对更新；新增 EXE、launcher env 和 app icon 也纳入增量清单。
- 官方域名与更新地址整理：
  - Stable 下载页：`https://65h26i.top/changebattle/`
  - Stable 更新清单：`https://65h26i.top/changebattle/latest.json`
  - Beta/debug 下载页：`https://65h26i.top/changebattle-beta/`
  - Beta/debug 更新清单：`https://65h26i.top/changebattle-beta/latest.json`
- Windows release 包新增 GUI launcher：
  - `ChangeBattle V2.exe`
  - `ChangeBattle-V2-Desk.launcher.env`
  - `resources/app-icon.ico`
  - `resources/app-icon.png`
- 固定应用图标使用关都徽章资源，后续若做运行时随机宝可梦小图标，会作为彩蛋单独推进。

## 0.2.0 候选版期间已收口的问题

- 灵魂伴侣亲密度结算已收口：战斗胜利后的亲密度会正确保留，最终结算时再同步回长期仓库。
- 灵魂伴侣携带道具同步已收口：正式局结束后，只同步灵魂伴侣自己身上的携带道具，不会误改其它宝可梦。
- 战斗中进化后的显示已补齐：进化后名称、图标、立绘、HP 面板等会一起刷新。
- 蛋生成规则已整理：孵化出的宝可梦不会异常默认全 31 个体值；全 0 努力值作为合理初始状态保留。
- 正式局结束后的蛋奖励流程已接入：最终胜利后选择候选、播放孵化演出、生成 50 级最小形态宝可梦，并写入玩家宝可梦箱子。
- 部分战斗播放测试脚本已修正，方便后续持续检查战斗表现。
- 优化训练家星图频繁保存导致的卡顿，清空节点时返还已消耗 BP。

## 测试关注点

- 新 EXE 启动：
  - 解压后双击 `ChangeBattle V2.exe` 能启动。
  - 启动时不弹 cmd 黑框。
  - 缺少 runtime 或 vendor 时有可理解错误提示。
  - `.cmd` fallback 仍可启动。
- 更新通道：
  - beta/debug 包读取 `https://65h26i.top/changebattle-beta/latest.json`。
  - stable 包读取 `https://65h26i.top/changebattle/latest.json`。
  - 增量 manifest 中包含 EXE、launcher env、resources icon、apps、assets、vendor。
- 灵魂伴侣：
  - 进入正式局时从仓库同步亲密度和携带物。
  - 单场胜利后亲密度能正确增长。
  - 最终结算后亲密度和携带物回写仓库。
  - 满亲密度 debug 战斗进化表现正确。
- 蛋与孵化：
  - 正式赛最终胜利后，符合条件时能从本局己方候选里选择一只。
  - 点击“就决定是你了”后能播放蛋孵化流程。
  - 孵化结果会生成该宝可梦进化链的最小形态，等级固定为 50，并送入玩家宝可梦箱子。
  - 孵化出的宝可梦基础数据正常，不再出现个体值全 31 的异常初始状态。
- 正式流程：
  - 开局、选人、休整、商店/训练、战斗、战后结算、最终结算可完整跑通。
  - 仓库、星图、BP、金币、道具和存档保存没有明显回退。
