# UI Reference Plan

本文档先列出 ChangeBattle 需要重新设计/对齐参考的关键页面。后续你找参考图时，可以按这里的页面编号补充截图、链接或描述。

当前原则：先不继续修现有 UI，先确定页面范围、信息层级和参考方向。

## 全局设计约束

- 默认逻辑画布：`640 x 320`
- 所有页面先按这个画布设计，再根据窗口尺寸等比缩放。
- 缩放应是全局机制，不是单独对战页面的临时适配。
- 页面内容需要避免依赖系统窗口大小硬编码。
- 核心信息优先级：当前状态 > 可执行操作 > 详情信息 > 辅助入口。
- 弹窗只用于详情、确认、复杂编辑；常用操作必须直接在主页面完成。

## P08-P12 对战页面组

这组优先级最高，因为当前问题集中在这里。

### P08 对战主界面

目标：稳定的三段式战斗 HUD。

建议信息结构：

- 顶部：我方队伍、回合/天气/场地/能力摘要、对手队伍。
- 中部：战斗场地、双方宝可梦、双方 HP 面板、动画/特效层。
- 底部：左侧战报，右侧 2x2 指令区。

需要参考：

- 经典宝可梦对战画面。
- Pokemon Showdown compact battle HUD。
- GBA/NDS 战斗场地布局。
- 能在小窗口和大窗口下都清晰的 HUD。

待解决问题：

- 宝可梦、平台椭圆、技能特效必须共用同一套坐标锚点。
- 顶部队伍栏不能遮挡战场。
- HP 面板不能被缩放裁切。
- 图鉴入口不能盖住关键状态。

### P09 技能选择

目标：四个技能按钮清楚、紧凑、可读。

必须展示：

- 技能名
- 属性
- PP
- 威力
- 命中或必中
- 效果提示/伤害预估

需要参考：

- Pokemon Showdown 技能按钮。
- 宝可梦正作四技能菜单。
- 小尺寸信息密集按钮。

### P10 宝可梦/换人

目标：点击宝可梦入口后可以快速看状态并换人。

必须展示：

- 队伍 3 只状态
- 当前上场标记
- HP/异常/睡眠/混乱等
- 能否换上

需要参考：

- Pokemon Showdown switch menu。
- 宝可梦正作队伍切换界面。

### P11 对局状态详情

目标：中间状态摘要点击后展开详情。

必须展示：

- 回合
- 天气
- 全场状态
- 我方场地
- 对手场地
- 我方能力变化
- 对手能力变化
- 最近战报

需要参考：

- 状态详情弹窗。
- 小窗口下可滚动详情面板。

### P12 战斗背包

目标：战斗中使用道具流程短且不会遮挡关键信息。

必须展示：

- 道具列表
- 道具说明
- 目标宝可梦
- 技能 PP 目标选择
- 使用按钮

需要参考：

- 宝可梦背包战斗使用界面。
- 紧凑 RPG 物品使用面板。

## P14-P22 休整页面组

这组是第二优先级，因为功能多、最容易堆成杂乱界面。

### P14 休整主界面

目标：不是“大资源四宫格”，而是队伍管理 + 主要操作入口。

建议信息结构：

- 顶部：第几场、金币、连胜、下一场入口。
- 主体：队伍 3 只紧凑列表。
- 操作区：交换、背包、购买道具、天赋、小道消息、下一场、中断。
- 状态反馈：本次休整已使用的天赋/操作以灰态标记。

需要参考：

- Roguelike camp/rest screen。
- 宝可梦队伍管理。
- 卡牌游戏商店/休息界面。

### P15 休整宝可梦详情

需要参考：

- 宝可梦详情页。
- 多页签信息面板。
- 技能/数值/道具管理。

### P16 休整背包

需要参考：

- 左列表右详情/目标选择。
- 道具使用后状态更新。

### P17 随机商店

需要参考：

- 抽卡/老虎机式商店。
- 商品卡片状态：未购买、已购买、不可购买、刷新中。

### P18 交换/盒子/孤注一掷

需要参考：

- 左右选择 + 中间交换确认。
- 已交换目标置灰/不可点击。

### P19 小道消息

需要参考：

- 赛程路线图。
- 敌方阵容逐步揭示。

### P20 本局天赋/天赋发动

需要参考：

- 被动效果列表。
- 主动天赋使用后灰态、已用标记。

### P21 技能调整

需要参考：

- 当前技能列表 + 候选技能列表。
- 技能详情预览。

### P22 数值调整

需要参考：

- 数值表格。
- 随机/重置按钮。
- 前后变化提示。

## P04-P07 开局页面组

### P04 天赋配置

目标：从“大量按钮堆叠”改成清晰路线/卡片/详情。

需要参考：

- Slay the Spire 遗物/卡牌图鉴。
- Hades 镜子/天赋升级。
- 技能树路线。

需要明确：

- 已解锁
- 未解锁
- 已装备
- 不可用
- BP 不足
- 当前选中详情

### P05 开局筹备升级

需要参考：

- 永久升级面板。
- 每项升级等级、消耗、效果。

### P06 开局道具选择

需要参考：

- 每阶段 draft。
- 已选择/跳过/下一步。

### P07 开局宝可梦选择

需要参考：

- 候选宝可梦详情。
- 已选队伍条。
- 重随、验牌、选择。

## P23-P25 其他页面

### P23 结算页

必须展示：

- 胜负
- 奖励
- BP/金币/统计
- 我方队伍
- 敌方队伍
- 下一步

### P24 图鉴

必须展示：

- 搜索
- 分类
- 结果列表
- 详情
- 技能/特性/道具/宝可梦信息

### P25 错误/确认/加载

必须覆盖：

- 操作失败
- 危险确认
- 加载遮罩
- 短 toast

## 下一步建议

1. 先找 P08-P12 对战页面参考。
2. 再找 P14-P17 休整与商店参考。
3. 最后找 P04-P07 开局与天赋参考。
4. 参考确定后，再重构文件结构：`pages/` 放页面，`components/` 放可复用 UI，`hooks/` 放全局交互与缩放。
