                                          来自神奇宝贝百科

                                          极巨化（日文︰ダイマックス，英文︰Dynamax）是一种寶可夢巨大化的現象，首次出现于《劍／盾》。在游戏开始时由木蘭博士研究其中的奥秘，现由她的孫女索妮亚和她的助手赫普来研究。

                                          概述

                                          在伽勒尔地区的能量点附近通过极巨腕带可以让宝可梦进行极巨化。从宝可梦体内释放出的特殊能量会扭曲周围的空间，使宝可梦看起来远远超过其实际大小。极巨化过后，宝可梦的体积会增大，ＨＰ会有所提升，并且所有招式都会变成极巨招式。极巨化只会增加ＨＰ上限，不会影响种族值。這個現象在几乎所有寶可夢身上皆有可能發生，只有苍响、藏玛然特及无极汰那无法进行极巨化，但无极汰那在剧情中可特殊地进行无极巨化。

                                          根据木兰博士的研究成果，极巨化时宝可梦本身没有变大，但是对方也能摸到它。

                                          宝可梦在进行极巨化后，除体积、体重和身高会增大数倍外，几乎所有寶可夢身上均形成暗红色的反光及在身体高处出现三朵灰紅色的雲，僅蕾冠王屬特例，極巨化時身上會形成藍色（而非暗紅色）的反光。

                                          能够进行极巨化的能量点如下：

                                          • 道馆竞技场（除尖钉镇）
                                          • 宝可梦巢穴
                                          • 洛茲大廈（对战塔）的塔顶
                                          • 能源工廠（只在無极汰那劇情中）
                                          • 对战竞技场
                                          • 马师傅武馆
                                          • 极巨巢穴

                                          极巨化等级

                                          极巨化等级共有0到10级共11个等级，可以在查看能力查看。可以通过极巨糖果来提升宝可梦的极巨化等级。

                                          极巨化等级 0级 1级 2级 3级 4级 5级 6级 7级 8级 9级 10级

                                          进行极巨化后，宝可梦的当前ＨＰ与最大ＨＰ会增大至（1.5+极巨化等级×0.05）倍（向下取整），相应地恢复为原来的样子后当前ＨＰ也将等比例减少（向上取整）。特别地，脱壳忍者的极巨化ＨＰ限定为1。

                                          对战机制

                                          每場对战中仅能使用一次極巨化，且在下场或經過3個回合後便會變回原本的樣子。

                                          • 極巨團體戰中有额外的对战机制，例如野生极巨化寶可夢永久保持極巨化的样子。

                                          極巨化寶可夢學會的招式全都會變成对应属性的極巨招式。

                                          • 极巨招式的ＰＰ与原招式的ＰＰ相同。
                                          • 所有的極巨招式都有追加效果，威力由原招式的威力计算。

                                          一些招式、效果对极巨化宝可梦与对一般宝可梦不同： [1] [2]

                                          • 一击必杀招式对极巨化宝可梦无效。
                                          • 巨兽斩、巨兽弹和极巨炮对极巨化的宝可梦造成的伤害是原来的两倍。
                                          • 极巨化宝可梦不会“被动”下场，包括强制拉对手的后备宝可梦上场的招式和对手的红牌。
                                            • 极巨化宝可梦可以“主动”下场，包括主动替换宝可梦或触发危险回避等特性及自身的逃脱按键；
                                          • 极巨化宝可梦不会被特性互换、找伙伴等招式以及游魂等特性改变特性，但对极巨化宝可梦使用烦恼种子和单纯光束依然能够成功。
                                            • 极巨团体战中的野生宝可梦使用接触类招式可以触发我方的木乃伊特性。
                                          • 极巨化后，宝可梦的替身消失。
                                          • 极巨化宝可梦不会陷入某些状态变化，并且这些状态变化在极巨化后解除，包括再来一次、定身法、畏缩、号令等。同命、封印等状态对极巨化宝可梦没有效果。
                                            • 极巨化宝可梦可以进入挑衅、灭亡之歌等状态。
                                            • 可以直接施加异常状态，若在极巨团体战中则对拥有神秘障壁的野生宝可梦无效。
                                            • 与超级进化、Ｚ招式类似，如果宝可梦的四个招式都无法使出，牠将不能极巨化，且只能使出挣扎。
                                          • 根据双方的体重影响威力的招式对极巨化宝可梦无效，包括踢倒、打草结、高温重压和重磅冲撞。
                                          • 极巨化宝可梦不会被限定招式，包括讲究头带、讲究眼镜、讲究围巾、特性一猩一意，它们也不会提升极巨化宝可梦对应的能力。但是极巨招式的ＰＰ耗尽后仍然无法使用。
                                            • 极巨化结束后，若宝可梦该次上场极巨化前没有使出招式，则可以自由选择招式仅一次，且享受能力提升；若使出过招式，则只能使用极巨化前使用的招式。
                                            • 突击背心依然正常生效，并且可以阻止携带者使用极巨防壁。
                                          • 强行特性对极巨招式无效。
                                          • 按固定比例改变极巨化宝可梦的ＨＰ，均按极巨化前的满ＨＰ计算需要改变的ＨＰ数值，包括且不限于愤怒门牙等招式、储水等特性、文柚果等道具、中毒等异常状态、诅咒、青草场地等状态变化。
                                            • 类似地，蛮干和分担痛楚也不考虑极巨化的ＨＰ增加倍数。
                                            • 治愈之愿回复极巨化后的满ＨＰ。
                                            • 软弱、鱼群特性按极巨化前的满ＨＰ计算何时发动，而茂盛、猛火、激流、虫之预感特性按极巨化后的满ＨＰ计算何时发动。
                                            • 按ＨＰ比例发动的树果按极巨化后的满ＨＰ计算何时发动。

                                          超极巨化

                                          超极巨化（日文︰キョダイマックス，英文︰Gigantamax）是一种特殊的极巨化现象，只有特定的个体能够发生超极巨化。超极巨化后宝可梦不仅会变大，样子还会变得更加凸显个性。它们除了会像通常的极巨化宝可梦一样提升ＨＰ以外，特定属性的攻击招式还会变化为超极巨招式，拥有不同于通常极巨招式的追加效果。一部分超极巨化宝可梦属于版本限定宝可梦。

                                          在《铠之孤岛》中，让有超极巨化可能性的宝可梦喝下极巨汤后，就会变为能够超极巨化的特别宝可梦。如果给已经能够进行超极巨化的宝可梦喝下，它反而会变得无法超极巨化，而只能极巨化。武道熊师只会喝下添加了极巨甜蜜的极巨汤，而美录梅塔无论如何都不会喝下极巨汤，目前只有通过活动赠送获得的美錄梅塔才能够超極巨化。

                                          能够超极巨化的皮卡丘、喵喵、伊布和鋁鋼龍不能进化和傳送至《劍／盾》以外版本，必須喝下极巨汤变得无法超极巨化后才能继续進化或傳送至其他版本。

                                          無極巨化

                                          無極巨化（日文︰ムゲンダイマックス，英文︰Eternamax）是只有無極汰那能夠發生的极巨化现象，收服無極汰那后，牠將無法再次進行無極巨化。無極巨化既是極巨化現象，也是無極汰那的形態變化，因此除了身形變大以外，種族值也會巨幅提升。作為極巨團體戰的對手，無極汰那（無極巨化）既能使用極巨招式，也能使用通常的招式。

                                          極巨团体战

                                          主頁面：极巨团体战

                                          極巨團體戰是挑戰野生極巨化寶可夢的一種戰鬥方式，由四名訓練家彼此合作，共同挑戰。野生極巨化寶可夢在對戰期間會一直維持巨大的樣貌，同時牠們还能够在一回合内使出多次招式，甚至会用特殊行动来消除我方宝可梦的特性及能力变化。四名訓練家當中只有一名訓練家能使自身的寶可夢極巨化。通过配合分工，在相應的時機發動極巨化令戰鬥獲得勝利。在對戰中取勝後，將會獲得收服該寶可夢的機會，並且收服時的特效震撼十足。極巨團體戰中可以遇到超極巨化的寶可夢或擁有隱藏特性的寶可夢，並且有極小的概率可以遇到既能超極巨化又擁有隱藏特性的寶可夢。

                                          《Pokémon GO》

                                          主頁面：極巨化（Pokémon GO）

                                          在8周年的贺图中，画面中央为极巨化的卡咪龟，预告了极巨化在游戏中登场。

                                          2024年9月4日登场的能量点页面和「巨大化之謎」特殊調查中，首次捕捉可以極巨化的寶可夢。

                                          極巨對戰在2024年9月10日登場。玩家能夠在地圖上的「能量點」進行極巨對戰、獲得極巨粒子，並指派寶可夢到能量點，以輔助其他玩家進行極巨對戰。

                                          集换式卡牌游戏中

                                          主頁面：宝可梦VMAX（TCG）

                                          动画中

                                          电视动画系列

                                          动画中的野生宝可梦在接触极巨化能量时，可自行实现极巨化或超极巨化。如果是拥有训练家的宝可梦，则训练家通常需要先把宝可梦收回精灵球中，随后通过极巨腕带发动极巨化，使精灵球变大后投出，如此宝可梦就会以极巨化的样子出现。变大后的精灵球看起来就像是放大版的纪念球，配有网格花纹。少数拥有训练家的宝可梦不需要进入精灵球即可实现极巨化。

                                          极巨化现象在卡比獸巨大化!? 極巨化的謎團!!中首次出现，小智和小豪受樱木博士委托来到伽勒尔地区的旷野地带调查极巨化现象，遇到了一只正在睡觉的卡比兽突然超极巨化，并成功阻止了一辆即将进站的列车与落在铁路上超极巨化卡比兽相撞。

                                          在极巨化对战！最强王者丹帝!!至小智VS丹帝！邁向最強之道!!中，丹帝和阿渡在宝可梦世界锦标赛的决赛上使用极巨腕带让喷火龙和红色暴鲤龙分别超极巨化和极巨化，进行对战。比赛结束后，火箭隊在竞技场外遇到一只野生的暴噬龟打算将其收服，他们派出的喇叭芽使出强力鞭打意外击毁地面导致极巨化能量涌了出来，暴噬龟因此超极巨化并失控，愤怒地袭击竞技场内，小智和小豪打算阻止它，过程中皮卡丘意外接触到极巨化能量而超极巨化，最终小智和皮卡丘在丹帝的提示下成功打败暴噬龟，使其恢复原状。第二天，丹帝邀请小智进行对战并送给他一只极巨腕带，过程中确认皮卡丘不需要进入精灵球就能进行超极巨化。

                                          由于极巨招式威力巨大，竞技场往往会设有隐形屏障，在极巨招式涌向观众席时起到阻挡作用，防止意外发生。

                                          细节

                                          • 增田順一及大森滋曾於訪談中開玩笑地表示極巨化其實是一種投影，讓寶可夢看起來好像變大了一樣。
                                          • 极巨化尤其是超极巨化设计原型可能源于法天象地。
                                          • 能超极巨化的皮卡丘、喵喵、伊布为特殊个体，无法进化。但是通过极巨汤解除可超极巨化状态后依然可以进化。
                                          • 能超极巨化的宝可梦培育出的后代无法继承超极巨化的能力，但可以通过马师傅武馆提供的极巨汤来实现超极巨化。
                                          • 由於視角问题及外貌幾乎相同，来悲茶和怖思壶难以辨别赝品形態与真品形態的分別，但可透过极巨化以更清楚地辨别。
                                          • 由於极巨化（含超极巨化、無极巨化）宝可梦的体重超过测量上限，因此皆会显示为???.?kg。
                                          • 因为场地原因，在游戏中，训练家的宝可梦极巨化（超极巨化）后位于训练家后方。但在动画中，却位于训练家前方。
