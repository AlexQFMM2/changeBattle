# ChangeBattle V2 Desk v0.1.0 测试版更新说明

这是 ChangeBattle V2 Windows Desktop 便携版的一次测试版更新。相比首版发布，本次重点不是继续扩大系统范围，而是围绕“正式流程可玩性、休息室体验、战斗表现、桌面端稳定性”做 v1.0 前的集中打磨。

本版仍然使用：

```text
ChangeBattle-V2-Desk-portable-v0.1.0.zip
```

玩家解压后运行：

```text
ChangeBattle-V2-Desk.cmd
```

## 本次更新重点

### 1. 正式流程难度与成长节奏调整

本版继续调整正式流程的养成压力，让每次休整选择更接近“资源决策”，而不是无成本补强：

- 玩家正式流程初始候选统一调整为 Lv.50。
- 训练课程费用统一调整为 200 金币。
- 自习课收益下调，不再轻易把个体值/努力值推到上限。
- 贪玩、一般、认真三档自习效果差异更明确。
- 训练课程说明改为更贴近课程定位的介绍文案。

这些调整的目标是提高正式流程的中后段压力，让玩家更需要思考钱要花在训练、治疗、商店还是交换上。

### 2. Gen7 Mega/Z 环境保障

本版补强了 Mega/Z 规则环境的实际可用性：

- Gen7 玩家初始候选中保底出现可 Mega 宝可梦。
- Gen7 NPC 队伍至少保证一个可 Mega 队员，并携带对应 Mega 石。
- NPC Z 纯晶配置优先考虑专属 Z。
- 专属 Z 会自动补齐所需招式，避免“有 Z 纯晶但实际用不出来”。
- 保留 Gen8 极巨化、Gen9 太晶化环境的原有保障逻辑。

这让不同世代规则的差异更清楚，NPC 也更容易打出对应世代的压迫感。

### 3. Battle V4 战斗解说与动画升级

战斗表现继续向“赛事转播”方向调整：

- 左侧解说改为事实型战斗解说，减少空泛气氛话。
- 解说跟随当前动画步骤，不再明显落后于战斗播放。
- 技能、命中、效果、天气、场地、回血、状态等信息会合并成更自然的解说。
- 新增能力变化解说：
  - 威吓降低能力。
  - 唱反调反转能力变化。
  - 好胜/不服输等特性触发提升。
  - 普通攻击、防御、特攻、特防、速度、命中、闪避升降。
- 新增能力变化动画：
  - 能力上升使用红/粉白光效，从下往上。
  - 能力下降使用蓝/青白光效，从上往下。

例如：

```text
君主蛇使用了飞叶风暴，本应下降的特攻因为唱反调而大幅提升了！
咆哮虎的威吓降低了帝王拿波的攻击！
帝王拿波的好胜被触发，特攻大幅提升了！
```

### 4. 战斗开场与结束叙事调整

正式战斗的叙事流程继续向赛事感靠拢：

- 开场由裁判宣布赛事阶段和双方选手。
- 双方角色再进行战前台词。
- 战斗结束后由裁判宣布失去战斗能力和胜利者。
- 角色再播放赛后台词。
- 赛程名称调整为更明确的阶段名称：
  - 小组赛揭幕战
  - 小组赛出线战
  - 十六强赛
  - 八强赛
  - 四强争夺战
  - 半决赛
  - 决赛

### 5. 休息室交互与弹窗层级修复

本版重点修复了休息室内多个容易影响测试体验的问题：

- 交换、治疗改为弹出窗处理，减少和休息室底层菜单互相遮挡。
- 修复部分公告栏/面板点击层级问题。
- 训练、商店页面改为点击后再渲染，减少不必要页面常驻。
- 调整训练/商店页面切换方向：
  - 点击训练后画面向左移动。
  - 点击商店后画面向右移动。
- 训练课程返回按钮改为“返回课程选择”，并修正返回行为。
- 交换面板改为通用对话框 + 大面板选择双方宝可梦。

目标是让休息室从“功能能打开”进一步变成“能稳定反复使用”。

### 6. 桌面端存档分表加密

本版重构了 V2 桌面端存档方式：

- 桌面端存档改为主进程统一管理。
- 使用 `saves-v2/slot-001/` 目录。
- `manifest.json` 保持明文索引。
- profile、训练流程、正式流程分别写入加密 `.dat` 表。
- 使用 gzip + AES-256-GCM 加密。
- 自动迁移旧 profile JSON。
- 自动迁移旧桌面 renderer localStorage 中的训练/正式流程存档。
- 删除资料时同步清理 profile、training run、formal run。

网页版仍保持 localStorage 行为不变。

### 7. 桌面端音乐接入

本版接入了 V2 桌面端音乐控制：

- 战斗、休息室、标题/非战斗场景开始具备对应 BGM。
- 桌面端增加音乐控制入口。
- release 包会携带本地音乐资源，不依赖网络。

音乐系统目前仍属于基础接入阶段，后续会继续调整曲目、切换时机和音量体验。

### 8. 图片、资源与 release 修复

本版修复了多处 release 包资源问题：

- 修复 staff 对话框立绘在 desktop release 中找不到的问题。
- 治疗、商店、训练、裁判对话框统一使用 `assets/npc/staff/` 资源目录。
- staff 对话框立绘改为通过 `<img>` 和统一资源解析加载，避免 CSS 变量中的相对路径在 release 下解析错误。
- 增强 renderer asset 检查，避免 `/npc/...`、`/showdown/...` 等根路径资源回归。
- 修复 Mega 路卡利欧等部分形态图片解析问题。
- 修复闪光宝可梦进入战斗页时立绘未使用闪光图的问题。

### 9. 正式结算统计修复

本版修复了正式结算中部分宝可梦贡献漏统计的问题：

- 结算统计不再只依赖最终队伍列表。
- 会从 battle log 中收集所有 p1 宝可梦的输出、承伤、治疗、击倒等贡献。
- 即使宝可梦后续被交换或不在最终队伍里，只要有战斗贡献，也应出现在结算 roster 中。

这能避免类似“雷丘明明打出过不少输出，但结算页不显示”的问题。

## 当前体验定位

本版已经进入 v1.0 前的稳定化测试阶段。

当前重点不再是无限扩功能，而是：

- 跑完整正式流程。
- 记录阻断问题。
- 修复战斗播放、休息室交互、资源缺失、结算统计等 bug。
- 继续调整钱、训练收益、NPC 队伍强度和决赛压力。

## 已知说明

- 当前仍是 Windows Desktop portable zip，不是安装器。
- release 包体较大，因为包含 Electron runtime、Showdown runtime、Showdown client、静态资源和桌面构建产物。
- `assets/` 资源目录仍不进入 git，但会进入 release 包。
- 测试阶段如果只是改资源，后续可以考虑做轻量资源补丁；涉及逻辑改动时仍建议重新构建测试包。
- 战斗演出、解说节奏、成长曲线和 NPC 队伍强度仍会继续通过人工测试调整。

## 本版适合测试的重点

- 从新正式流程开始，完整打完 7 场。
- 检查小组赛到决赛的难度上升是否自然。
- 检查训练、治疗、商店、交换的金币压力是否合理。
- 检查 Mega/Z/极巨/太晶环境下 NPC 是否真的会使用特殊系统。
- 检查战斗解说是否和动画同步。
- 检查能力变化、天气、场地、状态、回血等信息是否说清楚。
- 检查结算页是否正确统计所有有贡献的宝可梦。
- 检查 desktop release 中图片、音乐、存档是否正常。
