# 结算与价格规则

## 当前状态

以当前代码为准；文中未标 `[x]`、写明“后续/预留”或只描述方向的内容，均视为设计草案。

## 目前的基础结算规则

本文只写基础规则，不展开天赋影响。所有金币、BP、返还和价格都按无天赋状态理解。

基础货币换算：

```text
1 BP = 100 金币
金币折算 BP:
  floor(可折算金币 / 100)

BP 上限:
  99999
```

单场胜利奖励：

```text
击败训练师:
  +500 金币

失败 / 中断:
  不获得单场胜利奖励
```

整轮挑战基础配置：

```text
默认场数:
  7 场

通关条件:
  完成 7 连胜

通关后:
  当前整轮连胜 set_win_streak +1
  更新历史最高整轮连胜 best_set_win_streak
```

通关连续奖励：

```text
连续通关奖励金币 = (连续通关次数 * 2 + 7) * 100

例:
  第 1 次连续通关: 900 金币
  第 2 次连续通关: 1100 金币
  第 3 次连续通关: 1300 金币
```

失败和中断：

```text
战斗失败:
  本局结束
  当前整轮连胜 set_win_streak 归 0
  进入结算页

读档发现战斗未完成:
  视为挑战失败
  当前整轮连胜 set_win_streak 归 0
  进入结算页

休整页主动中断:
  本局结束
  当前整轮连胜 set_win_streak 归 0
  历史最高整轮连胜保留
  进入结算页
```

结算页金币处理顺序：

```text
1. 计算背包道具返还
2. 把返还金币加入本局金币
3. 计算可折算金币
4. floor(可折算金币 / 100) 转成 BP
5. 本局金币清零
```

背包道具返还：

```text
通关 / 主动中断:
  可返还道具价值 * 25%

战斗失败 / 战斗中断:
  可返还道具价值 * 10%

开局免费带走的道具:
  标记为 non_refundable
  这部分数量不参与结算返还
```

道具价值来源：

```text
优先使用 data/goods.csv 中 item 类型价格
如果找不到价格:
  默认按 500 金币
```

结算页显示内容：

```text
结果:
  WIN / LOST / ABORT

连胜:
  本局已完成胜场数

金币结算:
  本场胜利奖励
  连续通关奖励
  道具卖出总计

BP 结算:
  金币折算 BP

队伍表现:
  本局出现过的我方宝可梦
  击倒数、倒下数、造成伤害、承受伤害

进度:
  每场战斗的完成状态
  已遇到的训练师信息
```

## 当前的基础价格配置

### 休整交换

普通训练师战后交换：

```text
第 1 次交换:
  0 金币

第 2 次交换:
  100 金币

第 3 次交换:
  200 金币

每次休整最多交换:
  3 只
```

Boss 战后交换基础规则：

```text
馆主 / 四天王:
  默认只能交换 1 只
  基础价格 200 金币

冠军:
  默认不可交换
```

交换来的宝可梦基础状态：

```text
HP / PP:
  半血 / 半 PP 加入

携带道具:
  默认不保留敌方携带道具

原我方宝可梦:
  进入交换盒
  原携带道具回到背包
```

### 商店

商店抽奖：

```text
每次休整第 1 次抽奖:
  0 金币

后续抽奖:
  75 金币

每次抽奖商品格:
  3 格

每格候选池:
  4 个候选里按权重抽 1 个
```

购买商店商品：

```text
价格:
  使用 data/shop_pool.csv 中 cost 字段

技能机器:
  使用动态技能机器价格
  价格来自 data/goods.csv 的 skill 类型
  找不到时按招式威力估价
```

商店抽到重复商品：

```text
2 连:
  免费获得 1 个该商品

3 连:
  免费获得 2 个该商品

4 连:
  免费获得 3 个该商品

5 连及以上:
  免费获得 4 个该商品
```

### 背包和道具

使用消耗品：

```text
休整页使用:
  不花金币
  消耗 1 个对应道具

战斗中使用:
  不花金币
  消耗 1 个对应道具
```

装备 / 卸下携带道具：

```text
装备道具:
  0 金币
  从背包消耗 1 个

卸下道具:
  0 金币
  道具回到背包

替换已装备道具:
  0 金币
  原道具回到背包
  新道具从背包消耗 1 个
```

道具回收商基础规则：

```text
出现概率:
  每次战后休整 35%

出售价格:
  floor(道具价格 / 2)

出售后:
  背包该道具数量 -1
  获得对应金币
```

### 技能调整

抽取候选技能：

```text
价格:
  200 金币

候选数量:
  8 个

候选来源:
  当前宝可梦可学、且当前没有学会的招式

应用抽到的技能:
  0 金币
```

直接调整技能：

```text
价格:
  使用 data/goods.csv 中 skill 类型价格

如果 data/goods.csv 没有该技能价格:
  威力 >= 120: 800 金币
  威力 > 90: 650 金币
  威力 > 60: 500 金币
  威力 > 30: 400 金币
  其他: 300 金币

替换旧技能返还:
  floor(该技能格历史投入 / 2)
```

### 数值调整

随机重置数值：

```text
单项随机:

全部随机:

```

手动调整能力值：

```text

可调整:
```
